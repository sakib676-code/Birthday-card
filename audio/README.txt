PUT YOUR SONG HERE

1. Find the song you want (an .mp3 file).
2. Rename it to exactly:  song.mp3
3. Drop it into this "audio" folder, next to this file.

That's it. The site picks it up automatically.

If there is no song.mp3 here, everything still works —
the music button just stays hidden.

Want a different file name? Open index.html and change
   <audio id="bgMusic" src="audio/song.mp3" ...>
